# Inventory Data Cleaner

A simple JavaScript webpage that cleans a list of inventory data and displays only valid product names.

## How It Works

The project uses a `cleanData()` function with a `for` loop to:

- Remove non-string values.
- Remove empty or whitespace-only strings.
- Remove `"UNKNOWN_PRODUCT"` entries.
- Return a new array containing valid product names.

When the **Clean Inventory** button is clicked, the cleaned products are displayed as HTML list items.

## How to Run

1. Open the HTML file in a web browser.
2. Click the **Clean Inventory** button.
3. The cleaned inventory list will appear on the page.
